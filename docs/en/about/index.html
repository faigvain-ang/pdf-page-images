ABOUT / MAINTENANCE

Who maintains this notebook

Page Image Notes and PDF Page Images are maintained under faigvain-ang, by the same team developing related Eqvero, KolmoPDF and KomoPDF ecosystem tools. This is an associated educational project, not an independent review.

KomoPDF is the related product for local-first PDF editing, annotation and export. This separate open-source CLI offers only page-image rendering; it is not its editor, OCR engine or desktop application. It makes no promise about editing text or retaining digital-signature validity.

How this site works

Articles use synthetic data. This is a static educational site: commands run on your own computer, not in the browser. Runtime dependencies, if any, are installed separately as documented in the repository. No files are uploaded here, and there are no analytics, third-party fonts, CDN scripts, backend or login. The related cloud services have their own data handling.
