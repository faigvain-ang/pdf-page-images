About Page Image Notes

Page Image Notes explains how to export selected PDF pages to PNG or JPEG with predictable dimensions and original page numbering. The examples use a three-page PDF to demonstrate page ranges, DPI and rotation.

For editing text or adding annotations before image export, use KomoPDF. PDF Page Images handles the final rendering step locally, with explicit format and resolution settings.
