Renderice en local. Revise el resultado.

Python 3.11+ con versiones fijadas de PDFium y Pillow. Sin carga de archivos, OCR ni cuentas.

Código en GitHub →
python pdf_page_images.py examples/statement.pdf --pages 1,3 --dpi 144 --format png --output-dir out

Código, instrucciones de instalación y PDF sintético.

¿Necesita editar o anotar el documento antes de exportar sus páginas? Consulte el editor relacionado KomoPDF. Este CLI independiente renderiza imágenes, pero no edita el texto del PDF.
