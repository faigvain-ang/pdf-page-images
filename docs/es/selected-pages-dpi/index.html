Exportar páginas PDF con dimensiones previsibles

Un PDF sintético de tres páginas, una selección no consecutiva y una comprobación a 144 PPP.

Empiece con un documento sintético

El repositorio incluye un estado sintético de tres páginas. Sus páginas miden 612 × 792 puntos PDF. Un punto equivale a 1/72 de pulgada; a 144 PPP, una página sin rotación debe dar 1224 × 1584 píxeles. Así puede comprobar el proceso antes de usar documentos reales.

Clone el repositorio y cree un entorno local para las dependencias fijadas. En PowerShell de Windows:

git clone https://github.com/faigvain-ang/pdf-page-images.git
cd pdf-page-images
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe pdf_page_images.py examples/statement.pdf --pages 1,3 --dpi 144 --format png --output-dir out

En macOS/Linux, el intérprete del entorno es .venv/bin/python. La instalación descarga paquetes; el renderizado es local. Consulte en el README las versiones fijadas de PDFium y Pillow y sus licencias.

Compruebe identidad y dimensiones

Los archivos son statement-page-001.png y statement-page-003.png. La segunda imagen corresponde a la página original 3, no a una página 2 renumerada. Las etiquetas visibles de la muestra permiten comprobarlo. A 144 PPP la primera página de la muestra da 1224 × 1584. La tercera incorpora intencionadamente una rotación de 90 grados, por lo que su imagen da 1584 × 1224.

La selección cuenta páginas PDF desde 1. No interpreta numeración impresa como “iii” o “A-1”. Use una lista o rango, por ejemplo 1,3 o 1-3. Una página fuera de rango produce un error, no una omisión silenciosa.

Elija el formato de entrega

Para JPEG use --format jpeg. Revise las letras pequeñas al tamaño de visualización previsto. El resultado es una copia rasterizada, no texto editable, OCR ni un documento que conserve firmas. El PDF de origen no se modifica.

El producto relacionado KomoPDF ofrece un flujo más amplio de edición y anotación con prioridad local. Este CLI solo renderiza imágenes.
