ABOUT / MAINTENANCE

Quién mantiene este cuaderno

Page Image Notes y PDF Page Images se mantienen bajo faigvain-ang, por el mismo equipo que desarrolla herramientas relacionadas con Eqvero, KolmoPDF y KomoPDF. Es un proyecto educativo asociado, no una reseña independiente.

KomoPDF es el producto relacionado para editar, anotar y exportar PDF con prioridad local. Este CLI abierto es independiente y solo renderiza páginas: no es su editor, motor OCR ni aplicación de escritorio. No promete editar texto ni conservar la validez de firmas digitales.

El código y su historial se alojan en GitHub; este sitio web se publica en Vercel. Se mantiene la relación de mantenimiento compartido indicada arriba.

Cómo funciona este sitio

Los artículos usan datos sintéticos. Este sitio educativo es estático: los comandos se ejecutan en su ordenador, no en el navegador. Las dependencias, si existen, se instalan por separado según el repositorio. Aquí no se cargan archivos ni hay analítica, fuentes externas, scripts CDN, backend o cuentas. Los servicios en la nube relacionados gestionan sus datos por separado.
